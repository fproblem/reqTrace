# Бэклог ReqTrace

Единое место для идей и отложенных фич: что можно добавить, почему это ценно
и когда к этому подступаться. Обновлён: **2026-08-04** (ревизия: убраны
пункты, потерявшие смысл или перекрытые решениями из «Отклонено»).

Как вести:
- новая идея из обсуждения → сюда, с одной строкой «зачем»;
- взяли в релиз → кандидат уезжает из бэклога в план релиза (`docs/*.md`)
  и changelog; здесь остаётся только то, что ещё не делалось;
- отклонили → в раздел «Отклонено» с причиной, чтобы не предлагать заново;
- без привязок к номерам версий: где и когда что делалось — в changelog.

Живые дизайн-документы: `docs/anchoring-plan-v1.5.9.md` (модель привязок —
читать перед любыми правками привязок), `docs/auto-refresh-plan-v1.6.md`
(автообновление + дайджест).

## UX-пакет «удобство ежедневного цикла» (обсуждён 19.07.2026)

Фокус пользователя: удобство — главный фактор возвращаемости. Идеи вокруг
цикла «дайджест → проверить изменившееся → актуализировать → жить дальше».

- **Очередь проверки** (флагман-кандидат) — кнопка «Проверить всё» из
  дайджеста или с карточки проекта ведёт по всем outdated-привязкам проекта
  потоком: страница за страницей, прогресс «3 из 7», в конце — «всё
  проверено, закрепить baseline?». Убирает ручные прыжки дерево→страница→чип.
  ⚠ Переход к следующей — явным действием «Далее», не автоматикой
  (автопереход после «Актуализировать» уже откатывали — панель «прыгает»).
- **Глобальный поиск (Cmd+K)** (флагман-кандидат) — палитра: страницы по
  названию, тесты по ключу, проекты; пустое состояние — недавно открытые
  страницы. Делает инструмент «быстрым в руке».
- **Фильтр дерева по статусу привязок** — чипы «Требует проверки»/«Утрачено»
  над деревом; обзорное дополнение к очереди.
- **Контекст утраченной цитаты** — в панели у «Утрачено» показывать соседний
  текст (text_before/text_after): быстрее вспомнить, где жило требование.
- **Шпаргалка горячих клавиш** — клавиши уже есть (↑/↓, Escape, циклы по
  чипам), но невидимы; карточка по «?» и, возможно, пара новых клавиш.

Сознательно не вошло в обсуждение (оценка при брейншторме, пользователь не
утверждал): тёмная тема (дорого, вкусовое, конфликт с выверенной палитрой),
массовая «Актуализировать всё» (ломает принцип «статусы решает человек»).

## Очередь: обсуждено, ждёт своего часа

- **Отчёт о покрытии** (приоритет пользователя) + **экспорт CSV** — пара на
  отдельный релиз: витрина «Тестов» уже есть, не хватает выгружаемого среза.
- **«Изменившиеся страницы без задетых привязок»** — отдельный мягкий сигнал:
  правка в непокрытом тексте — невидимый риск. Частично закрыто строкой
  тишины в дайджесте («Страницы менялись, но привязки не задеты»);
  полноценный сигнал (какие именно страницы) — ждать запроса от жизни.
- **Группировка «Привязок без тестов» по страницам внутри раскрытия**
  (обсуждено 03.08.2026) — подзаголовки-группы по страницам, если раскрытие
  начнёт приезжать с десятками привязок; снаружи строка остаётся ОДНОЙ
  (решение: разбиение на строки-по-страницам вытеснило бы тесты с экрана,
  постраничный разрез — дело будущего отчёта о покрытии).
- **Ротация участника для ночного прогона** — распределение нагрузки на
  креды; осмысленно при больших командах.
- **Масштаб экрана «Тесты» дальше лёгкого списка** (из
  `docs/tests-performance-plan-v1.7.3.md`): серверная пагинация и поиск —
  порог «реверс-индекс от ~10k тестов» (раньше не надо: ломает мгновенный
  клиентский поиск); виртуализация списка — только если замер рендера
  покажет боль; `useDeferredValue` для поискового ввода — если ввод начнёт
  подтормаживать на многотысячных списках.
- Мелкий хвост: слить алерт notOnPage со статус-плашкой «Утрачено»; инвариант
  «Актуализировать» при отвязке последнего теста — обсудить, если всплывёт.

## Крупные фичи (каждая — свой релиз)

- **Мастер перепривязки для «Утрачено»** — «Утрачено» терминально; мастер
  помогает быстро создать новую привязку и перенести тесты.

## ⚠ Отклонено (решения пользователя — не предлагать заново)

- **Замена смайлов Confluence (⭐🙂✅❌👍❤️…) на иконки ReqTrace** (05.08.2026) —
  при чистке эмодзи v1.7.6 оставлены сознательно: это конвертация СОДЕРЖИМОГО
  страницы пользователя (ac:emoticon), а не интерфейс ReqTrace; в фирменном
  наборе нет эквивалентов (звезда, сердце, палец), подмена исказила бы документ.
  К тому же символы — часть координатного пространства привязок: убирать их из
  текста нельзя (см. _hidden_emoji в services/confluence.py).
- **Тезисы-онбординг на экране виртуальной страницы** (03.08.2026) —
  пробовали три пункта «что даст подключение» на IconBadge: читается грязно,
  дублирует модалку «Как работает ReqTrace». Пустые состояния держим лёгкими:
  заголовок + абзац; развёрнутые объяснения — дело онбординг-модалки.
- **Цветные статусные счётчики в чипах фильтров «Тестов»** (03.08.2026) —
  пробовали StatusCountPill в цвете смысла фильтра: на активном зелёном чипе
  получается цветовая каша. Счётчики фильтров — только нейтральные пилюли
  (как у «Привязанных тестов» в панели); цвет статусов — дело строк списка.
- **Вид нестандартного ключа теста** (19.07.2026) — закрыт как уже решённый
  двумя итерациями ранее (см. changelog): янтарная заливка строки снята,
  ключ-с-предупреждением не бывает ссылкой, тултипы объясняют. Остаток —
  вкусовой; без реальной жалобы не трогать.
- **Счётчик dead-тестов на карточке проекта** (19.07.2026) — перегруз
  относительно счётчиков утраченных привязок: от «Утрачено» избавляются сразу
  по появлении, поэтому тесты, потерявшие всю опору, и так вычисляются быстро
  (пометка «все утрачены» на ярусе 2 остаётся).
- **«В спейсах появились новые страницы» — в дайджест** (19.07.2026) —
  тестировщику новая страница не интересна, пока по ней не ведутся работы,
  а к моменту написания тестов она уже в дереве; не сыпать лишним в дайджест.
  Вместо неё сделана строка-подтверждение тишины.
- **Модалка-навёрстыватель первому вошедшему** (16.07.2026) — «будет надоедать
  модалкой на входе»; сценарий закрывают почасовой добор и кнопка на карточке.
- **Пакетный ввод тестов** — путает, что привязано; вернуться только если
  реально понадобится.
- **Автокомплит ключей тестов** — отклонён ОКОНЧАТЕЛЬНО (20.07.2026), даже
  с названиями из Jira: рабочий процесс — «создал задачу Test в Jira →
  скопировал присвоенный ключ → вставил», подсказки в него не встраиваются.
  Норма — атомарность «один тест на одну привязку»; тесты с 10+ привязками
  в БД — артефакт тестирования самого ReqTrace, а не реальный паттерн.
  (Первое отклонение v1.6.0: без названий дропдаун номеров неинформативен.)
- **Автопереход к следующему outdated после «Актуализировать»** — панель
  «прыгает» (пробовали и откатили; тост «Все привязки проверены» остался).
- **Оверлеи/sticky-тени таблиц** — только простые inset-тени `.table-scroll`.
- **Fade контента при листании привязок** (читается как переинициализация),
  **кольца фокуса** (фокус = потемнение рамки), **капитель ярлыков**.
- **Синий/фиолетовый в UI** — только фирменные цвета из `ICON_TINTS`
  (`components/icons.tsx`).
