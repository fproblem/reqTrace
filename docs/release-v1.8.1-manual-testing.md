# v1.8.1 «Удобство ежедневного цикла» — что появилось и как это проверить

Экспериментальный релиз: разобран UX-пакет бэклога целиком плюс CSV-срез,
две идеи «сверх плана» и прод-скрипт бэкапов. Ветка `release/v1.8.1`,
11 коммитов после v1.8.0. Файл — для ручной проверки перед решением, что
едет в релиз, а что в «Отклонено».

Состояние автоматики: **бэкенд 230 тестов** (было 226; +4 на CSV),
**фронтенд 114** (было 96; +18: контекст цитаты 5, поиск палитры 5,
недавние страницы 4, очередь 3, плюс перенумерация), `tsc --noEmit` чисто,
прод-сборка CRA без ворнингов. Миграций БД нет — откат
`git reset --hard v.1.8.0` без alembic downgrade.

По ветке прогнано адверсариальное ревью (10 независимых финдеров:
корректность, гонки, эффективность, конвенции, переиспользование…);
все подтверждённые находки исправлены отдельным коммитом `72d619cf`
(главные: Cmd+K не открывается поверх модалок — Esc закрывал обе; гонка
диплинков при быстрых «Далее»; Enter палитры по устаревшему индексу после
дозагрузки; нейтрализация CSV-формул и даты в поясе команды; кэш индекса
палитры вместо повторных штормов запросов; битые бэкапы при обрыве
pg_dump). Что осталось осознанно — в «Известных ограничениях» ниже.

## 1. Очередь проверки (флагман)

**Что:** на карточке проекта («Тесты», ярус 1) при ненулевом янтарном
счётчике появляется кнопка-пилюля **«Проверить»**. Она собирает все страницы
проекта с привязками «Требует проверки» (свежий срез дерева) и ведёт по ним
потоком: первая страница открывается сразу на первой такой привязке, внизу
экрана плавает бар «Проверка: N из M · название страницы · [Назад] [Далее]
[×]». Переходы — только явными кнопками (автопереходы в проекте отклонены);
«Назад» возвращает на предыдущую страницу очереди — страховка от случайного
«Далее». Ширина бара фиксированная: кнопки стоят на одном месте при любой
длине названия и разрядности счётчика. Внутри
страницы привязки обходятся как раньше: клик по цветной шапке карточки — по
кругу одностатусных, стрелки — все подряд.

**Проверить:**
- запуск с карточки; что «Проверить» не появляется при нуле янтарных;
- бар: прогресс, «Далее» → следующая страница с открытой панелью на
  ПЕРВОЙ ПО ТЕКСТУ outdated-привязке (порядок якорей, не порядок
  создания); на последней странице кнопка «Готово» → тост;
- «Назад» → предыдущая страница очереди (после случайного «Далее» место
  не теряется); на первой странице кнопка погашена, тултип объясняет;
- геометрия бара: длинное и короткое названия страниц — кнопки «Назад»/
  «Далее»/«×» не двигаются ни на пиксель (название уходит в эллипсис);
  смена «Далее» → «Готово» на последней странице кнопки тоже не двигает;
- клик по названию страницы в баре возвращает к текущей точке — в том
  числе когда вы УЖЕ стоите на этой странице с закрытой панелью (панель
  должна снова открыться на первой outdated);
- быстрый двойной «Далее» на медленной сети не открывает привязку одной
  страницы на другой (гонка починена по ревью);
- «×» сворачивает очередь; F5 тоже её закрывает (осознанно: в памяти);
- модалки («Удалить страницу?») открываются ПОВЕРХ бара;
- пограничное: пока очередь шла, привязки актуализировали с другой машины —
  «Далее» всё равно ведёт по снятому в начале списку (снимок, не live).

**Сознательные отличия от исходной идеи бэклога** (перефилированы в BACKLOG):
вход только с карточки проекта (из дайджеста — идея на будущее); финала
«всё проверено — закрепить baseline?» нет — пер-страничный тост «Закрепить
текущую версию?» уже существует после актуализации последней привязки.

## 2. Глобальный поиск Cmd+K

**Что:** ⌘K (Mac) / Ctrl+K — палитра над приложением: страницы по названию,
тесты по ключу и названию из Jira, проекты по имени. Пустой запрос —
недавно открытые страницы. Стрелки/Enter/Esc; кнопка-лупа в шапке — то же.
Тест открывается на «Тестах» проекта уже отфильтрованным (?q=ключ).

**Проверить:**
- хоткей в русской раскладке (e.code) и на альтернативных раскладках
  типа Dvorak (e.key); зажатая клавиша не «мигает» палитрой (e.repeat);
- хоткей из поля ввода (должен работать — стандарт палитр);
- поверх открытой модалки (например, «Добавить страницу») Cmd+K
  НЕ открывается — иначе Esc закрывал бы обе разом;
- поиск: страница/тест по summary/проект; подсветка совпадения; потолки
  групп (страниц ≤ 8, тестов ≤ 6, проектов ≤ 3);
- первое открытие: пока индекс едет — лоадер в поле; повторные открытия
  отвечают мгновенно из кэша, свежесть доезжает фоном; после изменения
  дерева (добавили/удалили страницу) кэш сбрасывается сам;
- Enter на тесте → ярус 2 с заполненным поиском; на проекте → ярус 2;
- Esc закрывает палитру и НЕ закрывает панель привязки под ней;
- проект без доступа (замок) в палитре не ищется;
- переход к странице раскрывает дерево на ней (отзыв): поиск и фильтр
  дерева сбрасываются, предки (проект → спейс → родительские страницы)
  разворачиваются, строка подъезжает в видимую область; работает и из
  «Недавнего», и с недавних на «/»; при СВЁРНУТОМ дереве раскрытие
  применяется при развороте рельсы (заявка живёт 15 секунд — позже
  разворот ведёт себя как обычно).

## 3. Фильтр дерева по статусу привязок

**Что:** в шапке дерева, на месте бывшего «плюса», — кнопка-воронка: по
тапу открывается поповер с двумя чипами-опциями «Ждут проверки» и
«Утрачены» (со счётчиками). Итог трёх итераций с пользователем: чипы
россыпью «сваливались в дерево», сегмент-контрол спорил за ширину узкого
сайдбара — поповер даёт чипам воздух, а шапке тишину. Выбор опции сужает
дерево до страниц с такими привязками (предки остаются — дерево связно),
раскрывает найденное, дружит с поиском; клик по активной опции снимает
фильтр. Пока фильтр активен — воронка зелёная; обе опции по нулям —
кнопка гаснет с тултипом; обнулился активный счётчик — фильтр сам
снимается.

**Проверить:** открытие/закрытие поповера (клик вне, Escape, повторный
тап); выбор опции закрывает поповер и подсвечивает воронку; совместная
работа с поиском; воронка гаснет, когда «тревожных» привязок нет
(актуализация последней янтарной — дерево перечитывается при переходах);
проект-«замок» не считается; клавиши ↑/↓/Esc панели привязки не
срабатывают при открытом поповере (role=menu).

## 3а. «Добавить страницу» переехала к проекту (по отзыву)

**Что:** кнопки-«плюса» в шапке дерева больше нет. Добавление страницы:
меню карточки проекта в профиле («Ещё действия» → «Добавить страницу»,
только при рабочем подключении), CTA на пустом экране «/», кнопка в
пустом дереве (проекты есть, страниц нет). Модалка переехала из PageTree
в Layout — событие reqtrace:open-add-page теперь слышно и при дереве,
свёрнутом в рельсу (раньше CTA на «/» в этом случае молча не работал).
Заодно пункт меню карточки «Обновить страницы сейчас» переименован в
«Обновить страницы» (слово лишнее — отзыв).

**Проверить:** добавление из меню карточки профиля (модалка открывается
поверх профиля, после добавления — переход на страницу, дерево
обновилось); CTA на «/» при СВЁРНУТОМ дереве; кнопка в пустом дереве;
выбор проекта в модалке, когда ссылка подходит двум проектам; пункт
«Добавить страницу» отсутствует у проектов без рабочего подключения.

## 4. Контекст утраченной цитаты

**Что:** в панели у привязки «Утрачено» цитата теперь показывается в
окружении соседнего текста снимка (приглушённые фразы до/после, сама
цитата полужирным). «…» по краям — только если окно захвата (100 символов)
упёрлось в кап. У старых привязок, созданных до захвата контекста, панель
выглядит как раньше.

**Проверить:** сделать привязку, удалить её текст в Confluence, обновить
страницу → «Утрачено» с окрестностью; привязка в начале страницы — без «…»
слева; выделение целого абзаца — контекст из соседних абзацев (склейка без
пробела между блоками — известное ограничение захвата, не относится к
этому релизу).

## 5. Шпаргалка горячих клавиш

**Что:** «?» (вне полей ввода) — модалка с разделами «Где угодно» /
«Страница требований» и подсказкой про клик по шапке-статусу.

**Проверить:** «?» в русской/английской раскладке (Shift+7 / Shift+/);
что НЕ открывается из поля ввода и поверх открытой модалки/меню; Esc
закрывает.

## 6. Экспорт среза покрытия в CSV

**Что:** на «Тестах» проекта (ярус 2), справа от фильтров — кнопка-таблица:
скачивает `reqtrace-покрытие-<проект>-<дата>.csv`. Строка = привязка × тест;
привязки без тестов — с пустыми колонками теста. Колонки: страница, спейс,
статус (по-русски), полная цитата, ключ, название теста из кэша Jira,
автор, дата создания, ссылка на Confluence. UTF-8 BOM + «;» + CRLF.

**Проверить:** открыть файл в русском Excel (кириллица без кракозябр,
колонки не разъехались), в Google Sheets; цитаты с «;» и переносами строк
остаются в одной ячейке; привязка с двумя тестами → две строки; демо-проект
выгружается; чужому проекту — 403 (можно curl'ом). По ревью: значения,
начинающиеся с «=», «+», «-», «@», получают ведущий апостроф (Excel/Sheets
его прячут) — формулы из Confluence не исполняются; даты — в поясе
AUTO_REFRESH_TZ (Москва), совпадают с датами на экране.

## 7. Недавние страницы (сверх бэклога)

**Что:** пустой экран «/» под кнопкой «Добавить страницу» показывает до
пяти недавно открытых страниц; пустое состояние Cmd+K — общий список
«Недавнее»: страницы визитов И тесты, выбранные в палитре (идея
пользователя по ходу проверки), одной хронологией до 10 записей. У тестов
хранится проект и название из Jira; при живом индексе название берётся
свежее — переименованный тест не висит под старым именем. Ключ хранения
ПЕРСОНАЛЬНЫЙ — с id пользователя сессии: аккаунты в одном браузере не
видят чужую историю (тоже отзыв пользователя; старый общий ключ
вычищается автоматически при первом визите).

**Проверить:** порядок (последнее событие — сверху), клик по странице
открывает её, по тесту — ярус 2 с заполненным поиском; выбрать тест в
палитре → он появился в «Недавнем» с иконкой теста и названием из Jira;
недавние отфильтрованы по живому индексу (удалённая страница и отвязанный
тест не предлагаются после загрузки); одинаковый ключ теста в двух проектах
— две записи; на экране «/» — только страницы, без тестов; войти под
ДРУГИМ аккаунтом в том же браузере — список пуст/свой.

## 8. Плашка «не отображается на странице» — внутрь карточки (мелкий хвост)

**Что:** редкий алерт рассинхрона больше не висит отдельной красной плашкой
над карточкой привязки — теперь это нижняя строка самой карточки, тем же
приёмом, что пояснение у «Утрачено».

**Проверить:** воспроизводится редко (рассинхрон снимка и привязок);
достаточно код-ревью + визуальной проверки, что у обычных привязок ничего
не изменилось.

## 9. Прод: backup.sh (без изменений в приложении)

**Что:** `./backup.sh` — ежедневный дамп БД в `backups/daily-<дата>.sql.gz`
с ротацией (последние 14; pre-update-бэкапы update.sh не задеваются),
поднимает postgres при необходимости, лог одной строкой под cron. README
«Эксплуатация» дополнен строкой crontab (04:30). **Осталось руками:**
прописать crontab на офисном Mac — пункт остался в BACKLOG.

**Проверить:** запустить `./backup.sh` на полигоне дважды — второй файл
появился, ротация не съела свежие; `gunzip -t` на файле.

## Известные ограничения (осознанно не чинил — кандидаты в бэклог/«норму»)

- **Недавние на «/» не сверяются с деревом** (в отличие от палитры): клик по
  удалённой странице ведёт на «Страница не найдена» с тостом; запись уйдёт
  из истории после десяти новых визитов. Сверка потребовала бы тянуть дерево
  на пустой экран — счёл перебором.
- **Очередь не прунит страницы, удалённые по ходу**: «Далее» на удалённую →
  тост об ошибке + пустая страница, следующий «Далее» выводит дальше.
- **«Проверить» на другом проекте поверх активной очереди** молча заменяет
  очередь (прогресс первой теряется); подтверждение не делал — редкий случай.
- **_STATUS_RU на бэке** — вторая копия словаря статусов (первая — statusLabels
  фронта); связаны комментариями, единого источника нет.
- **Пилюля «Проверить»** дублирует визуальные константы StatusCountPill —
  вынос общего pillStyle оставлен до следующей полировки.

## Решения, которые стоит принять по итогам ручной проверки

1. Очередь проверки: достаточно ли входа с карточки, или тянуть кнопку в
   дайджест (идея в BACKLOG)?
2. Нужен ли общий финал очереди с предложением baseline поверх
   пер-страничного тоста?
3. Cmd+K: не мешает ли перехват ⌘K из полей ввода? (Стандарт палитр, но
   вкус решает.)
4. Кнопка-лупа в шапке: оставить или довериться хоткею и шпаргалке?
5. CSV: хватает ли колонок (можно добавить anchored_text «текущий текст под
   маркером» второй колонкой цитаты)?
6. «Недавние страницы» на «/»: не спорит ли со стерильностью пустого экрана?
