# ReqTrace — код приложения

Полное описание проекта, возможностей, быстрый старт, конфигурация,
обновление и чек-лист прод-развёртывания — в [корневом README](../README.md).

Здесь живёт сам код:

- `backend/` — FastAPI (Python 3.12, async SQLAlchemy, Alembic), тесты в
  `backend/tests/`;
- `frontend/` — React + TypeScript (CRA), тесты рядом с кодом;
- `docker-compose.yml` + `.env.example` — развёртывание (см. корневой README).
