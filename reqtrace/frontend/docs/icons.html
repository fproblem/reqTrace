Иконки ReqTrace

Общая библиотека src/components/icons.tsx (появилась в v1.5.6). Все иконки — feather-стиль, viewBox 24×24, обводка currentColor. В плашке — оттенок, назначенный иконке в «Истории изменений»; серым ключ записи из changelog.json. Ниже плашки — та же иконка в размерах 12 / 16 / 24.

Как пользоваться

import { TrashIcon, SearchIcon } from '../components/icons';

<TrashIcon size={14} />
<SearchIcon size={13} strokeWidth={1.8} style={{ color: colors.textTertiary }} />

Цвет наследуется от color родителя; у всех по умолчанию display: block и flexShrink: 0. Иконки с поведением живут отдельно: RefreshIcon (вращение с докруткой) и XIcon в Modal.
