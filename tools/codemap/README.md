# codemap

Карта кода проекта (Python + TypeScript) — строит граф зависимостей и компактную
сводку для навигации. Цель двойная:

1. **Человеку** — увидеть архитектуру и связанность за минуту (Mermaid / Graphviz).
2. **LLM-агенту** — сориентироваться в коде, прочитав один файл `repomap.md`
   вместо десятков исходников (≈ в 10–15 раз меньше контекста).

Один файл, **только стандартная библиотека Python 3.8+**. Ничего ставить не нужно.

## Запуск

```bash
# полный прогон -> tools/codemap/out/
python3 tools/codemap/codemap.py

# окрестность файла (что я задену, если трону его) -> stdout
python3 tools/codemap/codemap.py --focus routers/pages.py
python3 tools/codemap/codemap.py --focus DiffView --depth 2

# только нужные форматы
python3 tools/codemap/codemap.py --format md,mermaid

# другой корень / каталог вывода / доп. исключения
python3 tools/codemap/codemap.py --root . --out build/codemap --exclude legacy,vendor
```

## Что на выходе (`tools/codemap/out/`)

| Файл | Для кого | Что это |
|------|----------|---------|
| `repomap.md` | LLM + человек | Ранжированная сводка: по файлу — слой, импорты, кто зависит, маршруты API, символы. Hotspots и мёртвый код — сверху. |
| `graph.json` | инструменты | Полные данные: узлы, рёбра, символы, маршруты, ранги. |
| `graph.mmd` | человек | Mermaid-диаграмма (рисуется в Markdown/GitHub без graphviz). |
| `graph.dot` | человек | Graphviz-исходник. Если установлен `dot` — рядом появится `graph.svg`. |

Картинку PNG/SVG из `.dot`: `brew install graphviz && dot -Tsvg out/graph.dot -o out/graph.svg`
(или вставь содержимое `graph.mmd` в любой Mermaid-просмотрщик / GitHub).

## Как этим пользуется агент

В начале работы над задачей:

1. `python3 tools/codemap/codemap.py` — обновить карту.
2. Прочитать `out/repomap.md` — общая картина + hotspots + мёртвый код.
3. Перед правкой конкретного файла — `--focus <файл>`: точная окрестность
   (импорты, зависимые, API-контур) вместо чтения всех соседей.

## Как читать `repomap.md`

- Файлы сгруппированы по слоям (routers / services / models / pages / …) и
  отсортированы по важности (**PageRank** по графу импортов).
- `↓N` — сколько файлов импортирует этот (fan-in), `↑N` — сколько импортирует он (fan-out), `★` — ранг.
- **Hotspots** — высокий fan-in: менять осторожно, заденешь многих.
- **Never imported** — никем не импортируется: кандидат в мёртвый код (проверь!).

## Что точно, а что эвристика

- **Python** разбирается через `ast` — импорты, классы/функции с сигнатурами,
  маршруты FastAPI (`@router.get(...)` + `prefix`), ORM-связи `relationship("X")`.
  Это **точно**.
- **TypeScript/TSX** разбирается регулярками — импорты и экспортируемые символы
  (компоненты, хуки, типы). Это **эвристика**: ловит ~95% обычного кода, может
  пропустить экзотический синтаксис. Достаточно для карты, но не для рефакторинга вслепую.
- Граница **HTTP** (фронтовый `api/client` → бэкендовый `main`) рисуется условно —
  это не импорт, а вызов по сети.
- Видны только связи через `import`/`from`. Связи через DI, события, строковые
  ключи или рантайм-резолвинг граф не покажет.

## Настройка под проект

Значения по умолчанию заданы константами вверху `codemap.py`:
`DEFAULT_EXCLUDE_DIRS`, `DEFAULT_EXCLUDE_FRAGMENTS`, и функция `detect_layer()`
(маппинг путь → слой). Под другой проект правится там же.
